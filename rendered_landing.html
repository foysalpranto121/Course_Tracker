Features

Everything you need to run a study plan

Four core tools that cover the whole loop — see where you stand, decide what to do next, record the work, and move the data in or out.

Analytics dashboard

Overall completion percentage, active enrolments and per-course milestone progress, recalculated on every visit.

Context-aware AI tutor

An assistant that reads your active courses to draft seven-day study plans, practice quizzes and deadline reminders.

Excel import and export

Bulk-import spreadsheets with automatic duplicate detection, then export tracking reports back to Excel in one click.

Task and deadline manager

Set deadlines per course, track completion status, and notify instructors automatically when work is finished.

Under the hood

Built on a production Django stack

Server-rendered Django with a managed PostgreSQL database, static assets served by WhiteNoise, and continuous deployment from the main branch.

Django 6.1 PostgreSQL Gunicorn WSGI WhiteNoise Render Cloud

Request and data flow

  1. Client request

    A learner browses the dashboard or opens the AI assistant.

  2. Middleware

    IP filtering, session handling, request logging and performance timing.

  3. Class-based views

    The Django ORM queries PostgreSQL and aggregates progress.

  4. Response

    Templates render server-side and ship with cached, compressed static assets.
